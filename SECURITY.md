# Security Policy

## Supported versions

This is a static personal website. Only the `main` branch, which is what runs in production, is supported.

## Reporting a vulnerability

Please do not open a public issue. Use GitHub private vulnerability reporting instead:

1. Open the repository's **Security** tab.
2. Click **Report a vulnerability**.
3. Describe the issue, the affected page or file, and steps to reproduce.

I aim to acknowledge reports within about a week and to share a fix or an assessment as soon as reasonably possible. This is a personal project, so there is no formal SLA.

## Scope

In scope: the site's own code, build and CI configuration in this repository.

Out of scope:

- Cloudflare and other third-party services
- Denial of service or volumetric attacks
- Automated scanner output without a working proof of concept
